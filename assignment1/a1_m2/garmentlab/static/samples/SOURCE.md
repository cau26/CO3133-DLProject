# Fashion-MNIST demonstration samples

These three PNG files preserve the original 28×28 grayscale pixels from the
official **training** images. They are interface examples, not an evaluation
set or evidence of model quality. They were selected by the first original
training ID for the stated label, without checking model predictions.

| PNG | Original training ID (zero based) | Label |
|---|---:|---|
| sample-tshirt.png | 1 | 0 — T-shirt/top |
| sample-trouser.png | 16 | 1 — Trouser |
| sample-boot.png | 0 | 9 — Ankle boot |

Source: [Fashion-MNIST, Zalando Research](https://github.com/zalandoresearch/fashion-mnist).
The dataset authors are Han Xiao, Kashif Rasul and Roland Vollgraf.
